# 🚀 我的 Slidev 簡報工廠

這個倉庫是我專屬的 Slidev 簡報管理中心。透過「單一環境、多專案」的架構，節省磁碟空間並快速啟動新簡報。

## 📂 目錄結構

- `_template/`：簡報範本。包含基礎設定與常用 Frontmatter。
- `node_modules/`：共用的依賴庫（所有簡報共用，不需重複安裝）。
- `202X-XX-簡報名稱/`：各個獨立的簡報專案。
  - `slides.md`：簡報主文件。
  - `assets/`：該簡報專用的圖片或資源。

---

## 🛠️ 開發常用指令

### 1. 開始一份新簡報
不需要重新初始化！只需從範本複製：
```bash
# 複製範本到新資料夾
cp -r _template 2024-XX-新簡報名稱
```

### 2. 啟動開發環境 (Preview)
在根目錄執行，記得加上 `--` 來傳遞路徑參數：
```bash
# 啟動特定簡報
npm run dev -- 2024-XX-新簡報名稱/slides.md

# 或者如果你裝了 VS Code 擴充功能：
# 直接打開該 .md 檔案，點擊右上角「播放」圖示
```

### 3. 匯出簡報 (Export)
將簡報轉換為 PDF：
```bash
npm run export -- 2024-XX-新簡報名稱/slides.md
```

### 4. 構建靜態網頁 (Build)
生成用於部署的靜態檔案：
```bash
npm run build -- 2024-XX-新簡報名稱/slides.md
```

## 💡 備忘小筆記

1. **指令中的 `--` 是什麼？**
   它是 npm 的特殊語法，表示「後面的路徑參數是要傳給 Slidev 的，而不是傳給 npm」。
2. **圖片路徑：**
   在 `slides.md` 引用圖片時，請使用相對路徑，例如：`![Alt](./assets/my-pic.png)`。
3. **VS Code 神器：**
   確保已安裝 `Slidev` 官方擴充功能，它可以讓你在編輯時同步看到右側的即時預覽。
4. **快捷鍵：**
   - `O`：投影片總覽。
   - `?`：查看所有快速鍵（畫筆、簡報模式等）。

### 🎁 額外的小貼士：
如果你之後想把這份「簡報工廠」上傳到 **GitHub** 或雲端備份，別忘了建立一個 `.gitignore` 檔案，內容寫上：
```text
node_modules/
dist/
*.pdf
```
這樣就不會把那幾百 MB 的依賴包一起傳上去了，備份會非常輕量！
